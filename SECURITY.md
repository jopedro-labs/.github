# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, credential leak, or policy flaw in any repository under the **jopedro-labs** organization:

1. **Do NOT create a public GitHub issue.**
2. Send a private security report directly to **João Pedro** ([@JoPedro15](https://github.com/JoPedro15)) via GitHub's [private vulnerability reporting](https://github.com/jopedro-labs/.github/security/advisories/new).
3. Include the following in your report:
   - Detailed steps to reproduce the vulnerability
   - Affected repository, components, and file paths
   - Potential impact and severity assessment
   - Any proof-of-concept code (if applicable)

### Expected Response Timeline

| Stage                  | Target                                       |
|:-----------------------|:---------------------------------------------|
| Initial acknowledgment | Within 48 hours                              |
| Triage & status update | Within 5 business days                       |
| Fix & patch release    | Within 14 business days (severity-dependent) |

## User Responsibility

You are solely responsible for protecting any credentials, API keys, OAuth tokens, or webhook URLs used when running projects from this organization. The author is not liable for unauthorized access or data loss resulting from leaked secrets or improper local configuration.
