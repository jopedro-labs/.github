### Core-Lib Content & Utilities

* 📊 **`core_lib.logger`:** Structured terminal logger with ANSI colors and timestamps.
* 📁 **`core_lib.file_utils`:** Safe file-loading utilities designed to read content cleanly without throwing exceptions.
* ☁️ **`core_lib.gdrive`:** OAuth2 Google Drive client supporting credential management, remote folder access verification, file existence checks, safe uploads with optional overwrite, downloads, and automated backup sync.
* 💬 **`core_lib.discord`:** Discord webhook client and notifier (`DiscordNotifier`) for sending automated status notifications, rich messages, and system alerts.
* 🛡️ **Autonomous Quality Agent:** Internal developer utility (`scripts/quality_eval_agent.py`) powered by Gemini AI for continuous test gap analysis, coverage evaluation, and validation across the 5 core software quality pillars[cite: 1, 16].

### Finances-Data Modules & Clients

* 📈 **`finances_data.yahoo_finance`:** Yahoo Finance integration client for fetching real-time market quotations, historical prices, and stock/ETF fundamentals with robust error handling.
* 🔍 **`finances_data.just_etf`:** Resilient web-scraping client for JustETF profile pages, extracting ETF holdings, sector and country breakdowns, Total Expense Ratio (TER), and fund metadata with fallback parsing strategies.
* 🛡️ **Autonomous Quality Agent:** Internal developer utility (`scripts/quality_eval_agent.py`) powered by Gemini AI for continuous test gap analysis, coverage evaluation, and validation across the 5 core software quality pillars in the data client repository[cite: 14, 15].
