### Core-Lib Content & Utilities

* 📊 **`core_lib.logger`:** Structured terminal logger with ANSI colors and timestamps.
* 📁 **`core_lib.file_utils`:** Safe file-loading utilities designed to read content cleanly without throwing exceptions.
* ☁️ **`core_lib.gdrive`:** OAuth2 Google Drive client supporting credential management, remote folder access verification, file existence checks, safe uploads with optional overwrite, downloads, and automated backup sync.
* 💬 **`core_lib.discord`:** Discord webhook client and notifier (`DiscordNotifier`) for sending automated status notifications, rich messages, and system alerts.
* 🛡️ **Autonomous Quality Agent:** Internal developer utility (`scripts/quality_eval_agent.py`) powered by Gemini AI for continuous test gap analysis, coverage evaluation, and validation across the 5 core software quality pillars.

### Finances-Data Modules & Clients

* 📈 **`finances_data.yahoo_finance`:** Yahoo Finance integration client for fetching real-time market quotations, historical prices, and stock/ETF fundamentals with robust error handling.
* 🔍 **`finances_data.just_etf`:** Resilient web-scraping client for JustETF profile pages, extracting ETF holdings, sector and country breakdowns, Total Expense Ratio (TER), and fund metadata with fallback parsing strategies.
* 🛡️ **Autonomous Quality Agent:** Internal developer utility (`scripts/quality_eval_agent.py`) powered by Gemini AI for continuous test gap analysis, coverage evaluation, and validation across the 5 core software quality pillars in the data client repository.

### Finances-Manager Pipelines & Capabilities

* 📸 **Snapshot Pipeline:** Automated broker position capture (XTB screenshots) parsed via Gemini Vision multimodal extraction, reconciling totals, FX, and persisting to SQLite.
* ⚖️ **Quantitative Scoring & Allocation:** Deterministic scoring engine combining dip discount, forward P/E, 52-week ranges, TER fees, and portfolio target gaps with look-through exposure capping (country, sector, company).
* 📊 **Quality & Analytics Audits:** Fundamental tier classification (Tier A/B/C), ATH & maximum drawdown time-series tracking, and multi-horizon compound growth simulations (10/20/30-year horizons).
* 📝 **Automated AI Reports:** Daily portfolio review and rebalancing advisory generation in HTML and Markdown powered by Gemini analyst agents.
* ☁️ **Google Drive SSoT:** Two-way synchronization (`make gdrive-push` / `make gdrive-pull`) ensuring a single source of truth for SQLite databases and configuration files.
